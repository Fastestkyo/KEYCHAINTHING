# KEYCHAIN THING

**Slack Username:** @karnx (U082Z7WDHSQ)

---

## 🧠 What is this?

KEYCHAINTHING is a tiny, hackable keychain PCB created for the [#solder](https://solder.hackclub.com) channel at Hack Club.

It features:

- 🔘 A **pushbutton** that activates a **vibrating mini motor disc**
- 🎛️ A **potentiometer** that controls the brightness of **two LEDs**
